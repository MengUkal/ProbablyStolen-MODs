## 三、P2 做空 + 限价委托（2026-11-04 晚已实现）

> 「做空执照」(800) 不再是空气。以下规则已按定稿落地，实现细节可直接读代码。

### 3.1 做空（已实现）

- 前置：账户 T3（`stock.exchange.short`）；规则：开空=卖出借来的股（现金不动，只扣开仓手续费 1%）；**借券费 0.5%/日**（入睡结算扣现金，现金不足扣到 0 为止，差额计入已实现盈亏）；**保证金 150%**：`现金+持仓净值 ≥ 空头总市值×150%`（定稿口径，不含空头浮盈）；**强平线 120%**：`(现金+持仓净值+空头浮盈) < 空头市值×120%` 时全部空头按当日收盘强制平掉（UI 消息+日志警告）
- 平空盈亏 = `(开空均价 − 现价) × 数量 − 费用`；亏损超出现金时现金扣到 0 为止（不记欠款）
- 空头市值计入单股持仓上限（T3 = 20,000）
- 代码落点（与原计划一致）：`MarketData.cs`（`shortQty[]`/`shortAvgCost[]`/`OnDaySettled()` 钩子 + 老存档字段归零兜底）、`Broker.cs`（`TryOpenShort`/`TryCloseShort`/`MaxShortable`/`ChargeBorrowFee`/`CheckMarginCall`，三个比率是常量：`BorrowRatePerDay=0.005`、`MarginOpenRatio=1.5`、`MarginCallRatio=1.2`）、`ExchangeUI.cs`（T3 加开空/平空按钮、列表 "空 N" 标记、详情空头行）

### 3.2 限价委托（已实现）

- `PendingOrder{idx,side,shares,limit}`，side：0=买 1=卖 2=开空 3=平空；`ExchangeState.orders` 列表随档持久化
- 每日结算按当日新收盘价撮合：买/平空 `收盘 ≤ 限价` 成交，卖/开空 `收盘 ≥ 限价` 成交（滑点 0，照收 1% 手续费）；卖出/平空数量超出持仓→作废并提示；现金/保证金校验失败→作废并提示（不做部分成交）；上限 20 条
- UI：T3 详情区加「委托」小节（挂单列表 + 撤销）；限价输入在开平空按钮旁
- 通知机制：`Broker.PushNotice()` 落 Debug.Log + UI 刷新时底部消息条显示（委托成交/作废/强平）

### 3.3 验收标准（对照策划案 §10，待游戏内实测）

- 做空全流程：开空→借券费按日扣→价格下跌获利平空 / 强平触发
- 限价单：低于限价买入成交、高于限价卖出成交、撤单不残留
- 连续 10 游戏日 + 反复读档无报错，存读档一致（重点：空头与委托的 JSON 兼容）

## 四、技术坑清单（血泪换来的，动代码前先读）

1. **`PlayerStore.Instance` 是惰性构造单例，主菜单期访问会 NRE**（ctor 抛异常 → MOD 被标记 Init failed → LoadLocalization 被跳过 → 本地化字典全空）。全 MOD 只允许在游戏场景内（`StoreUIManager.Instance != null` 哨兵之后）碰它。
2. **`StoreStation.Instance` 同为惰性单例**，且游戏自身用 `StoreStation.Instance == null` 做局内判断（AfterhourEvents、RunStats 等）——菜单期碰它会构造假对象污染游戏判断。场景哨兵统一用 `StoreUIManager.Instance`（Awake 赋值的普通单例，菜单期安全为 null）。
3. **暗网升级只能在读档/新游戏回调里注册**（`EnsureUpgradesRegistered`）：`RegisterModUpgrade` 内部触碰 PlayerStore（坑 1），且本地化需 `LoadLocalization` 完成后可用；注册幂等（按 id RemoveAll+Add）。
4. **暗网卡片按 subtitle 分组**：多个升级共用同一 subtitle 字符串才会归入同一组（现在是「环带交易所」）。subtitle 是**注册时求值的字符串**，title/desc 是惰性 Func（渲染时求值）。
5. **独立随机源**：市场用 `System.Random(seed)`（种子入档 `stocks_seed_v1`——实际在 `stocks_state_v1.seed` 里）。**绝不调用游戏 RNG 类**（全局共享流，消耗会改变原版顾客/掉落随机序列）。
6. **结算幂等**：`lastSettledDay` 水位 + 单次最多补 40 天（宁可断档不可重算，防读档刷价）。跨存档隔离靠 `OnGameLoadedNormal → ReloadForGameLoad()`（先清内存态）。
7. **本地化 CSV 规则**（ModLoader.LoadLocalization）：首个半角逗号分 key/value，值可 `"..."` 包裹（内含 `""` 转义），`\n` 换行，`#` 注释行。文件名=语言代码（zh/en）。Func 标签是惰性的，注册时的"key not found"警告无害（渲染时会重新求值）。
8. **编辑工具会把 .ps1 的 UTF-8 BOM 弄丢** → Windows PowerShell 5.1 解析报错。改完 `build.ps1` 后检查前三个字节，不是 `EF BB BF` 就用 pwsh 重写补 BOM（交接时的命令：`[IO.File]::WriteAllText($p, [IO.File]::ReadAllText($p, UTF8), [UTF8Encoding]::new($true))`）。
9. **JsonUtility 需要引用 `UnityEngine.JSONSerializeModule.dll`**（csproj 已加，新工程别忘了）。
10. **DeveloperMode 信任自动刷新**：enable-mod 注入的信任记录带 developerMode=true + Local 来源时，ModLoader 对 hash 不匹配自动放行并刷新指纹——**改完 DLL 重启游戏即生效，无需重新批准能力**。
11. CustomUI 注意：`AddButton` 高度来自预制体（别塞两行文本，会被裁）；`CustomUIElement.SetFixedWidth/SetImageColor/SetTextColor` 是排版主力；左右分栏 = `BeginRow + BeginPanel(固定宽,-1) + BeginPanel(-1,-1)`。
12. 游戏事件→股价映射表在 `EventLink.cs`（36 条，identifier 与 `StoreEventManager` 蓝图一致）；游戏更新后跑 `gen-patch-targets.ps1` 复查。
